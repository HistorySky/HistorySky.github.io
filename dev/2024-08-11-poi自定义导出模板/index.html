POI自定义导出模板

发表于： 2023-07-27
字数： 2048 阅读：≈ 5分钟 浏览：

深度实践：如何用 Java 打造一个“聪明”的 Excel 导入模板？

在企业级应用中，Excel 导入导出是极其高频的需求。一个“好用”的导入模板不应只是简单的标题行，它还应该具备：清晰的数据类型约束、直观的下拉选择框、以及标准化的单元格样式。

本文将分享如何使用 Apache POI 打造高级 Excel 模板，并简要对比 EasyPOI 的快速实现方案。

1. 原生 POI：构建全功能动态模板

如果你的需求涉及复杂的格式控制或数据校验（如强制下拉列表、特定的小数位数），原生 POI 是唯一的选择。

1.1 核心挑战：样式与性能

在生成大批量 Excel 时，一定不要在循环中创建样式。我们应该预先定义一个 CellStyleMap。

Java

/** * 生成常用样式 Map，避免重复创建 Style 导致文件损坏或内存溢出
 */
private Map<String, CellStyle> buildCellStyleMap(XSSFWorkbook workBook) {  
    XSSFDataFormat format = workBook.createDataFormat();  
    Map<String, CellStyle> styleMap = new HashMap<>();  
  
    // 标题样式：加粗、居中
    XSSFCellStyle titleStyle = workBook.createCellStyle();  
    Font headerFont = workBook.createFont();  
    headerFont.setBold(true);  
    titleStyle.setFont(headerFont);  
    titleStyle.setAlignment(HorizontalAlignment.CENTER);  
    styleMap.put("标题", titleStyle);  
  
    // 金额样式：强制保留 6 位小数
    XSSFCellStyle decimalStyle = workBook.createCellStyle();  
    decimalStyle.setDataFormat(format.getFormat("0.000000"));  
    styleMap.put("金额", decimalStyle);  
  
    // 百分比样式
    XSSFCellStyle percentageStyle = workBook.createCellStyle();  
    percentageStyle.setDataFormat(format.getFormat("0.00%"));  
    styleMap.put("百分比", percentageStyle);  
  
    return styleMap;  
}

1.2 高级进阶：添加隐藏页数据校验

为了防止用户录入错误数据，我们通常会在 Excel 中加入“下拉选框”。如果下拉项很多，直接硬编码在数据校验里会导致 Excel 公式溢出。 最佳实践： 创建一个隐藏的 Sheet 存放选项，再通过 Name 引用实现联动。

Java

/** * 给指定列添加下拉列表校验
 */
public static void addValidationToSheet(Workbook workbook, Sheet targetSheet, String[] options, int column) {  
    int numberOfSheets = workbook.getNumberOfSheets();  
    String hiddenSheetName = "data_source_" + numberOfSheets;  
    Sheet optionsSheet = workbook.createSheet(hiddenSheetName); // 创建隐藏页
    
    // 1. 在隐藏页写入选项数据
    for (int i = 0; i < options.length; i++) {  
        optionsSheet.createRow(i).createCell(0).setCellValue(options[i]);  
    }  
  
    // 2. 创建名称管理器引用（绝对引用）
    Name name = workbook.createName();  
    name.setNameName("dict_column_" + column);  
    name.setRefersToFormula(hiddenSheetName + "!$A$1:$A$" + options.length);  
  
    // 3. 设置数据有效性
    DataValidationHelper helper = targetSheet.getDataValidationHelper();  
    // 引用隐藏页的内容
    DataValidationConstraint constraint = helper.createFormulaListConstraint("dict_column_" + column);  
    CellRangeAddressList regions = new CellRangeAddressList(1, 65535, column, column);  
    DataValidation validation = helper.createValidation(constraint, regions);  
    
    validation.createErrorBox("输入错误", "请从下拉列表中选择预设选项！");  
    targetSheet.addValidationData(validation);  
    
    // 4. 隐藏数据源页
    workbook.setSheetHidden(numberOfSheets, true);  
}

2. 效率工具：EasyPOI 的编程式导出

如果你不需要复杂的隐藏页校验，只是想快速导出一个带标题的模板，EasyPOI 提供了更加声明式的写法。

不需要在代码里逐行 createRow 和 createCell，通过 ExcelExportEntity 即可快速定义结构：

Java

private List<ExcelExportEntity> getExportEntities() {  
    List<ExcelExportEntity> entityList = new ArrayList<>();  
    // 构造对象等同于在实体类上使用 @Excel 注解
    entityList.add(new ExcelExportEntity("结算月份", "monthPeriod"));  
    entityList.add(new ExcelExportEntity("合作伙伴", "partnerName"));  
    entityList.add(new ExcelExportEntity("结算总额", "totalAmount"));  
    entityList.add(new ExcelExportEntity("分成比例", "shareRate"));  
    entityList.add(new ExcelExportEntity("状态", "statusDesc"));  
    return entityList;  
}

这种方式非常适合于列名动态变化的导出场景。

3. 完整演示：生成一个带校验的财务对账模板

为了演示 cellStyleMap（样式管理）和 addValidationToSheet（数据校验）的协同工作，我们编写一个生成“供应商对账模板”的方法。

3.1 业务代码实现

在这个示例中，我们将创建一个包含“供应商名称（下拉选择）”、“结算月份（文本）”和“结算单价（金额格式）”的 Excel。

Java

/** * 生成并下载供应商对账模板
 */
@PostMapping("/downloadDynamicTemplate")
public void downloadDynamicTemplate(HttpServletResponse response) throws IOException {
    // 1. 初始化响应头 (脱敏处理：通用模板下载)
    HttpUtils.buildExcelResponseHeader(response, "Financial_Settlement_Template", ".xlsx", true);
    ServletOutputStream outputStream = response.getOutputStream();

    // 2. 创建工作簿与样式池
    XSSFWorkbook workbook = new XSSFWorkbook();
    // 使用 cellStyleMap 预先定义样式，避免在循环中重复创建
    Map<String, CellStyle> styles = cellStyleMap(workbook); 
    
    XSSFSheet sheet = workbook.createSheet("对账数据录入");

    // 3. 创建标题行
    String[] headers = {"供应商名称", "账期(yyyyMM)", "结算单价(元)", "结算方式"};
    XSSFRow headerRow = sheet.createRow(0);
    for (int i = 0; i < headers.length; i++) {
        XSSFCell cell = headerRow.createCell(i);
        cell.setCellValue(headers[i]);
        cell.setCellStyle(styles.get("标题")); // 应用标题样式
        sheet.setColumnWidth(i, 20 * 256); // 设置基础列宽
    }

    // 4. 应用列级默认样式（防止用户输入变成科学计数法或丢失精度）
    // 将第二列（账期）设为文本格式
    sheet.setDefaultColumnStyle(1, styles.get("文本")); 
    // 将第三列（单价）设为金额格式（保留6位小数）
    sheet.setDefaultColumnStyle(2, styles.get("金额")); 

    // 5. 注入动态数据校验
    // 场景：供应商列表通常从数据库实时查询
    String[] supplierOptions = {"华为终端有限公司", "腾讯云计算", "阿里巴巴宝船"};
    String[] settleWays = {"底价模式", "比例分成"};

    // 为第一列（供应商）添加下拉框，覆盖前1000行
    addValidationToSheet(workbook, sheet, supplierOptions, 0, 1, 1000);
    // 为第四列（结算方式）添加下拉框
    addValidationToSheet(workbook, sheet, settleWays, 3, 1, 1000);

    // 6. 输出文件
    workbook.write(outputStream);
    outputStream.flush();
    outputStream.close();
}

4. 经验总结

在处理 Excel 相关开发时，有几点心得分享：

  1. 自适应列宽： 使用 sheet.autoSizeColumn(i) 后，建议再乘以一个系数（如 1.5），因为原生 POI 对中文字符的宽度计算不够准确。

  2. 默认列样式： 通过 sheet.setDefaultColumnStyle(column, style) 可以预设一整列的格式（如将整列设为“文本”或“日期”），即便用户下拉新增行，格式依然生效。

  3. 兼容性： 导出模板时建议使用 .xlsx 格式（XSSFWorkbook），它对大数据量的支持和容错性远优于旧版的 .xls。
